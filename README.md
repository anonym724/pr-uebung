# pr-uebung

Dieses Repository dient als Uebung fuer den ersten Pull Request.

## Was ist ein Pull Request?

Ein Pull Request (PR) ist ein Vorschlag, Aenderungen in ein Repository einzufuehren.
Der Workflow sieht so aus:

1. Branch erstellen
2. Aenderungen committen
3. PR oeffnen
4. Review + Merge
